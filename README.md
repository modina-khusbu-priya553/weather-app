# SkyNow Weather App

A weather app built with plain HTML, CSS and JavaScript (no frameworks).

**Live site:** [your GitHub Pages link]

## Features
- Search for a city or use your GPS location
- Current weather, 24-hour forecast and 7-day forecast
- Weather data from three providers: Open-Meteo, MET Norway and OpenWeatherMap
- Chart comparing the providers' hourly temperatures
- Favorites, and °C / °F / K switch
- Page colors change with the weather

## Project structure
- `index.html` - main page
- `css/style.css` - styles
- `js/script.js` - application logic
- `Weather-App project report.pdf` - project report

## Tools
Chart.js, Font Awesome, Google Fonts (Manrope)
